# Wireshark Network Traffic Investigation

## Project Overview

A hands-on SOC analyst training project focused on investigating network traffic using **Wireshark**. The project consists of six interactive labs designed to develop practical skills in identifying attackers, analyzing network communications, uncovering hidden data, detecting exposed credentials, and investigating suspicious activity.

## Objectives

- Identify suspicious IP addresses and potential attackers.
- Analyze network communications using Follow TCP Stream.
- Discover hidden information within captured traffic.
- Identify usernames and passwords transmitted over HTTP.
- Detect brute-force attacks through repeated login attempts.
- Analyze VoIP traffic and investigate scam calls.

## Labs and Exercises

| # | Lab | Focus |
|---|---|---|
| 1 | Identify the Attacker's IP | Attacker identification |
| 2 | Follow TCP Stream 1 | Network conversation analysis |
| 3 | Follow TCP Stream, Part 2 | Hidden data investigation |
| 4 | HTTP Plain Text Credentials | Credential exposure |
| 5 | Catch the Brute Force Attacker | Brute-force detection |
| 6 | Catch the Call Scammer | VoIP traffic investigation |

Each lab contains **10 tasks**, providing 60 practical exercises in total.

## Tools & Technologies

- **Wireshark** – Network protocol and packet analysis.
- **TCP Stream Analysis** – Reconstructing network conversations.
- **HTTP Analysis** – Investigating clear-text credentials.
- **VoIP Analysis** – Examining voice communication traffic.
- **PCAP Files** – Captured network traffic for investigation.

## Learning Outcomes

- Develop practical network traffic analysis skills.
- Recognize suspicious network activity and attack patterns.
- Understand how credentials can be exposed through insecure protocols.
- Identify brute-force behavior through packet analysis.
- Investigate VoIP communications and suspicious calls.
- Build foundational SOC analyst investigation skills.

- Perform investigations only within the provided labs.
- Never capture or analyze traffic from networks without ownership or written authorization.
- Attempt each task independently before using hints.
